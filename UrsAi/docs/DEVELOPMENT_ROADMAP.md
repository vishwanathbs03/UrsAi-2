# Development Rules

Always continue from the first unfinished milestone.

Never rebuild completed work.

Never replace deterministic engines.

Never duplicate existing functionality.

Reuse existing APIs whenever possible.

Maintain backward compatibility.

---

# Milestone Completion Checklist

A milestone is complete only if:

- Feature implemented
- Backend complete (if applicable)
- Frontend complete (if applicable)
- APIs registered
- Schemas updated
- Existing functionality preserved
- Verification passed
- Documentation updated

---

# What Must Never Be Rebuilt

The following systems already exist and should be reused:

- Authentication
- Business Profile
- Intelligence Engine
- Score Engine
- DNA Engine
- Rule Engine
- Knowledge Engine
- AI Decision Engine
- Recommendation Engine
- Roadmap Engine
- Scenario Simulator
- Digital Twin
- OCR Engine

These systems are considered stable.

Future work must extend them instead of replacing them.
